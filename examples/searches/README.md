# Recorded real discovery example

raghavi-c01.json is an unchanged copy of [the saved c01 retrieval result at upstream revision 259d2a9](https://github.com/YYU035/NLP_Project/blob/259d2a9e90fb8e9d5988f030a156733f4f3576d1/live_search/artifacts/depth-approved-run/c01.json).

It contains 32 unranked candidates from the saved depth experiment, source/query diagnostics and canonical identities/aliases. It is a cached retrieval record, not current search output or annotated scientific evidence. The original claim and encoding are retained exactly; no medical interpretation or verdict is added. Abstracts/descriptions and PDF URLs are metadata only.

The native payload has no retrieval timestamp. The frontend leaves that unknown, displays the exact source revision/path, and permits selection/export with a checksum. No provider calls are made when loading this example. Live-search smoke results are separate ignored outputs, not substituted for this fixture.
