# Poster assets

- PROJECT_POSTER_A3.pdf: one vector A3 landscape page,420×297mm, verified for text overflow and key results.
- PROJECT_POSTER_PREVIEW.png: readable preview of that PDF.
- PROJECT_POSTER_A3.svg: editable vector/text source.
- PROJECT_EXPLAINED.md: child-friendly walkthrough, Mermaid technical diagram, model identities, dependencies and metric definitions.
- DEPENDENCIES.json: all118 installed environment distributions and versions, including optional/dev/transitive packages; not all are direct runtime requirements.
- build_poster.py: reproducible local builder using the already installed PyMuPDF.
- LAYOUT_CHECKS.json: the68 checked text boxes, physical page size and zero-overflow result.

The verified editable Canva version was imported from the exact vector PDF, then checked through Canva's text/page APIs. The Canva edit/view links are supplied in the chat and stored privately in the ignored outputs/poster/CANVA_LINKS.json, rather than published in the Git repository. The initial generated draft contained errors and is not the final deliverable.
